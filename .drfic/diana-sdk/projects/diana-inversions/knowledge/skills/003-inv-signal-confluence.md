# 003-inv-signal-confluence — Signal Confluence

## Objetivo

Definir la validacion de señales de compra y venta mediante confluencia de cores, score configurable y razonamiento explicable.

## Criterios de exito

- Las señales solo son validas con confluencia suficiente.
- El razonamiento queda trazable y auditable.
- No se producen señales black-box.

## Fallback

Si falta esta skill, desactivar validacion automatica de señales y reportar gap 003-inv-signal-confluence.
